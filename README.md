# ZQU4TRO Academia

Site de conversão da ZQU4TRO Academia, no Boqueirão, em Santos. Layout responsivo em preto e amarelo, com modalidades, grade de aulas, localização e contato direto pelo WhatsApp.

## Executar

O projeto usa HTML, CSS e JavaScript, sem instalação de dependências e sem etapa de compilação. Abra `index.html` ou sirva a pasta com um servidor estático:

```sh
python -m http.server 8080
```

## Publicar

Configure o serviço de hospedagem para servir a raiz deste repositório. O arquivo de entrada é `index.html`. Pode ser publicado em GitHub Pages, Cloudflare Pages, Netlify ou outro serviço de arquivos estáticos.

## Conteúdo

- `index.html`: conteúdo e estrutura da página.
- `style.css`: estilos e adaptações para celular.
- `app.js`: seleção de modalidades e mensagens do WhatsApp.
- `assets/`: logo original e sete imagens ilustrativas geradas em alta resolução, otimizadas em WebP.

As imagens de treino são ilustrativas e não representam fotografias das instalações ou dos alunos da academia. O logo foi fornecido pelo responsável pelo projeto.
